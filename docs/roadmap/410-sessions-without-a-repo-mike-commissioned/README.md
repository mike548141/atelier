# Sessions without a repo (Mike commissioned, 2026-09-29)

His words: *"We need better support for situations where I run claude code
sessions without a repo - small jobs, shaping ideas etc"*.

Every onramp this house has is a repo's `CLAUDE.md`, and every close-out it
asks for — the session log, the board, commit and push, worktrees — assumes a
tree to write into. A session opened outside any repo inherits the person-level
instructions and a per-directory memory, and nothing else: no read order, no
record, no board, and no route for what it produces to reach the repo it
belongs in.

**Not hypothetical, measured at filing:** the home-directory project holds 28
session transcripts, and two of the seven peers live alongside this filing
session were opened outside any repo.
