### Findings

**PS1 — MAJOR (design/scope). The wired scope cannot see the motivating
case class, and the anchor set false-positives on the convention root files
actually use.**
Claim: S2's first citation is a root README naming `docs/decisions/`
(`tools/pathscan.py:10-11`), yet the CI step scans `docs` only
(`.github/workflows/ci.yml:148`) — root `README.md`, `CHANGELOG.md`,
`CLAUDE.md`, `SECURITY.md` are unscanned, so the scanner as wired cannot
catch its own motivating shape. And when root files *are* scanned
(whole-tree run), the dominant root convention — docs-relative shorthand —
false-positives because anchor 3 requires a `docs/` *ancestor*
(`tools/pathscan.py:425`): `README.md:51` (`method/REVIEW.md`, which exists
as `docs/method/REVIEW.md`) and 50 of CHANGELOG.md's findings are this
exact shape.
Evidence: whole-tree run above; `README.md:51`; CHANGELOG.md 50/246.
Counsel: add a fourth anchor — `<root>/docs/<token>` for files not under
`docs/` — which by the tool's own stated invariant ("widening resolution
can only DROP a finding", `tools/pathscan.py:75-77`) is safe, then include
root-level `*.md` in the gated scope. This is a precondition of any flip.

**PS2 — MINOR (undocumented false negative). Emphasis-wrapped paths are
invisible.** Claim: `**docs/x.md**`, `*docs/x.md*` and `_docs/x.md_` are
all missed (probe-confirmed) — the token lookbehind excludes `*` and `_`
is `\w` (`tools/pathscan.py:245`), so no match can start inside emphasis
markers. The header's FALSE NEGATIVES list (`tools/pathscan.py:105-124`)
does not name this mode, and the header's honesty about FN modes is
load-bearing. Bold-plus-backtick (`` **`docs/x.md`** ``) is caught.
Counsel: at minimum add the mode to the docstring's FN list; optionally
strip `*`/`_` emphasis runs before token-hunting.

**PS3 — MINOR (probe-confirmed false-positive mechanism, live on the
shipped surface). Line-local placeholder blanking misses multi-line
placeholders.** Claim: `_ANGLE_PLACEHOLDER` runs per line
(`tools/pathscan.py:248,302-317`), so a `<...>` span wrapped across a line
break escapes blanking — live at
`docs/build/templates/docs/decisions/template.md:4`, where
`docs/reviews/YYYY-MM-DD-HHMM-slug.md` sits inside a wrapped
`<queued — ... >` span and is flagged; the `YYYY-MM-DD`-pattern
placeholder token also matches none of the placeholder exemptions.
Counsel: document the line-local limit beside the existing
line-local-regex caveat, and consider a date-pattern placeholder exemption
(`YYYY`, `HHMM`); the allow-marker hatch covers it meanwhile.

**PS4 — MAJOR (gate scope). The baseline is ~97 % records; the gateable
surface is the doctrine surface, where the scanner already has one genuine
catch.** Claim: hand-classification of the 177-finding docs baseline:
143 under `docs/reviews/` + `docs/sessions/` (incl. 3 withdrawn), 23 in
root-level records (ROADMAP-DONE 12, SESSIONS 9, ROADMAP 2), 5 in
`docs/decisions/`, 6 on the live doctrine surface (`docs/method/` +
`docs/build/`). Records are point-in-time: they legitimately name
historical paths (`tools/scaffold.py`), other repos' trees
(`tiki/docs/ARCHITECTURE.md`, ros `docs/PRINCIPLES.md`), ephemeral
worktrees (`.claude/worktrees/...`), and self-qualified estate paths
(`atelier/docs/ROADMAP.md`) — the scanner has no time axis, so records can
never come clean without mass allow-markers. The doctrine surface's 6:
**1 true positive** — `docs/build/README.md:28` names
`tools/check_links.py`, renamed to `tools/linkscan.py` (a genuine stale
pointer, the scanner's headline live catch) — and 5 false positives:
`docs/build/REPO-STANDARD.md:96,100` (`.claude/settings.local.json`,
gitignored *by documented design*), the PS3 template line, and
`docs/method/00-APEX.md:248` + `docs/method/EVIDENCE.md:265` (ros's
`docs/PRINCIPLES.md`, the header's own named external-repo FP mode — live
on the apex doc itself). `docs/decisions/` adds the dropped-intermediate-
directory shape (`templates/CLAUDE.md` meaning
`docs/build/templates/CLAUDE.md`, ×3) no anchor can resolve.
Counsel: gate on the doctrine surface only (`docs/method`, `docs/build`,
arguably `docs/decisions` after markers) — the same scope-to-doctrine move
the wrapscan WS1 review made — with records advisory or `.pathscanignore`d.
A did-you-mean basename hint in the finding detail would make residual
triage cheap.

**PS5 — MINOR (fleet posture). The advisory wiring is a bespoke `ci.yml`
step outside the `tools/floor.py` registry — the exact vendored-policy

**PS6 — MINOR (documented exemption, undocumented masking consequence).**
