## Learnt

- 🔎 Workers stamp at-rest dates from their context clock (NZDT), not `date -u`:
  two of three wrote 2026-11-17 on a 2026-11-16 UTC run. Corrected in one commit;
  later dispatches say "use `date -u`" in the prompt.
- 🔎 A pointer file created for a later landing, left untracked, made `board
  --rebuild` bake it into an earlier landing's index; the hook refused. Rebuild
  with `--from-index` after staging.
- 🔎 A full Python suite run in the primary checkout took over 10 minutes at
  load 11–22; stopped by its task id, the change it covered was pinned by
  `test_templates` alone.
- 🔎 A landing script that stops on a dirty tree (`set -e` at its `git pull`)
  was followed in the same command by the worktree teardown, joined with `;`,
  so the branch was deleted unlanded. Recovered from its sha within a minute
  (`git branch <name> <sha>`), landed, then torn down. Teardown now runs only
  on a landing's success (`&&`).
