# Economics: effective first, then efficient — budgets and real spend counted (Mike commissioned, 2026-11-12)

His commission, in his words, recorded verbatim:

> I need to update the doctrine economics to take Claude budgets vs actual
> expenditure over and above plan costs into account more. This principle is
> still the same, we use the right model for the job and to be right the model
> must be effective which means capable of understanding and delivering the
> quality required that the specific job requires. There is a big difference
> between capabilities to do research, to develop code, to test code, to
> provide insights, and to write great papers (advice, reports, presentations
> etc).
> Secondly to be right it must be the most efficient model for the job, and
> that does not always mean the cheapest per token which is where we need to
> consider are we using Claude's weekly budget, platform API and other things
> that cost real money over and above my Claude plan at the time. That includes
> costs outside Claude like GitHub actions minutes etc. Sometimes a "more
> expensive" model like fable will deliver a job cheaper and to the same or
> better quality than "cheaper" models like opus, sonnet, and haiku.
